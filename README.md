# Codex Relay

macOS 菜单栏应用：勾选一个或多个 Codex 本机任务，明确因额度耗尽而失败后，等待额度实际恢复，在原会话发送续跑消息。

[下载 Apple Silicon 版本](https://github.com/afetmin/codex-relay/releases/latest) · [第三方来源与许可证](THIRD_PARTY_NOTICES.md)

## 安装与构建

需要 Apple Silicon Mac、macOS 15 或更新版本，以及受支持的 Codex 桌面端。发布包使用本机临时签名，未经过 Apple 公证。也可以在本机从源码构建：

```sh
git clone https://github.com/afetmin/codex-relay.git
cd codex-relay
./build.sh
open "Codex Relay.app"
```

构建需要 Xcode Command Line Tools；运行所需的 Node.js 路径见下文。

## 使用

1. 双击 `Codex Relay.app`，保持 Codex 桌面端运行并登录。
2. 点击菜单栏的循环箭头，选择“选择监控任务…”。
3. 搜索任务名称或项目路径，勾选要监控的任务。可以选择多个。
4. 保持“启用自动续跑”开启。续跑消息可以修改并保存。
5. 关闭窗口后监控继续运行；退出菜单栏应用会停止监控。

初次打开没有任务被自动勾选，需由你选择。

任务每 30 秒检查一次，账户额度通常每 60 秒刷新；每次实际续跑前再次查询额度并复核会话。5 小时与每周窗口共享于账户，等待所有已耗尽窗口恢复，不固定等待五小时。多个所选任务按顺序复核并启动。

监控名单在应用重启后保留。Mac 休眠时不检查，唤醒后继续；没有配置开机自启动。Codex 重启后会重连，必要时只重新打开你勾选且历史显示执行中或额度失败的原会话。

## 续跑条件

- 最新一轮必须是结构化 `UsageLimitExceeded` / `usageLimitExceeded` 错误。
- 正常完成、手动中止、其他错误、等待审批或输入、已有排队消息，不会触发续跑。
- 实际发出消息前重新确认会话所有者、最新一轮、模型、权限、工作目录与相关设置。原会话的模型、推理和权限设置由桌面端继承。
- 任务被归档、取消勾选或全局暂停后，不再发送后续消息；已经被 Codex 接受的消息不能撤回。
- 已发送记录持久化；响应丢失等不确定情况不会自动重发。请检查原会话。新的一轮出现后，监控可以继续判断。
- 若恢复后再次遇到额度错误，至少间隔两分钟再评估下一次续跑。

## 环境与边界

- 本次构建：Apple Silicon，macOS 15 或更新版本。
- 已验证连接的 Codex 桌面版本：`26.1013.31256` / build `20586`，默认安装在 `/Applications/ChatGPT.app`。
- 使用私有本地 IPC。版本升级后会暂停自动操作，需要适配并重新验证。
- 需要 Node.js 22 或更新版本。会优先查找 Homebrew 的 Node；也可使用当前 Codex 应用附带的 `cua_node/bin/node`。不需要 npm 安装依赖。
- 若账户存在多个额度桶或其他独立限制，当前版本停止推测，显示需要确认。
- 只管理本机持久会话，不管理云端任务或临时子代理。
- 能恢复执行轮次，不能保证任意长任务最终完成。

## 本地数据

配置、所选任务与最近 150 条简短记录位于：

`~/Library/Application Support/Codex Relay/state.json`

文件权限为当前用户读写。应用不会读取或导出账号令牌，不购买额度，不兑换重置次数，不代替你批准工具请求。额度与任务列表通过 Codex 自身的只读 App Server 连接获取；实际续跑通过桌面端的会话所有者发送。

系统文件锁防止重复应用实例。发送前保存意图和已处理轮次，防止程序重启后重发同一次中断。没有修改 Codex 的安装文件或用户配置。

## 验证情况

已完成：

- Swift 原生构建、临时本机签名校验、Info.plist 校验。
- 在本机读取真实额度、任务列表和当前会话实时状态。
- 原生窗口、任务搜索与列表显示检查。
- 隔离端到端回放 14 项通过，涵盖多任务恢复、原会话目标、设置继承、额度等待、重复抑制、持久记录、正常完成、手动停止、其他错误、审批等待、全局暂停、归档、发送结果不确定和检查中取消选择。

尚未完成：使用真实任务从额度耗尽跨越自然重置边界，再确认自动续跑。回放使用本机模拟 Unix 通道，没有向真实任务发送消息。没有新增单元测试。

## 源码与重新构建

- `Sources/RelayApp.swift`：原生菜单栏、任务窗口、搜索、设置和运行记录。
- `Resources/monitor.mjs`：本地通道、额度查询、监控和持久记录。
- `./build.sh`：编译并生成 `Codex Relay.app`，使用本机临时签名。

只读诊断：

```sh
node Resources/monitor.mjs --diagnose
```

该命令只验证连接和读取额度、少量任务列表，不会发送续跑消息。
